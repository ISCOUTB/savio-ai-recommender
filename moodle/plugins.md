# Bloques/plugins de Moodle para Entrega 2

Estado: pendiente de guia del docente.

Necesarios segun fuentes de Entrega 2:

- Estilos de Aprendizaje.
- Personalidad.
- CHASIDE / orientacion vocacional.

Regla: no implementar estos instrumentos desde cero. Se instalan desde IS-UTB o repositorio oficial de Moodle y se diligencian con el equipo.

Checklist:

- [ ] Moodle local accesible.
- [ ] Plugin/bloque de Estilos instalado.
- [ ] Plugin/bloque de Personalidad instalado.
- [ ] Plugin/bloque CHASIDE instalado.
- [ ] Tres integrantes diligencian tests.
- [ ] Resultados exportados o transcritos a fixtures JSON.
