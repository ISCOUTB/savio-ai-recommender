# fuentes - Documentos base del proyecto

Aqui se colocan los documentos entregados por la direccion del proyecto
(planteamiento de las entregas). **No se versionan en git** por tamano y porque
no son produccion del equipo; esta carpeta solo guarda este README con la
trazabilidad.

## Ficha de custodia

Completar cuando el equipo confirme el dato. No inventar rutas.

| Campo | Valor |
|---|---|
| Custodio | por confirmar |
| Ubicacion | por confirmar (Drive, Teams o correo del docente) |
| Ultima actualizacion conocida | por confirmar |
| Quien puede solicitar copia | equipo del proyecto |

## Regla

- Si alguien necesita el documento, lo pide al custodio; no se commitea.
- Toda referencia a estos documentos en la documentacion apunta a este README,
  no a una ruta que puede no existir.
- Si el docente entrega una version nueva, se actualiza la tabla y se anota la
  fecha en `experimentos/bitacora.md`.
