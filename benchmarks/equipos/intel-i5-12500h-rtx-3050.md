# Equipo Intel Core i5-12500H + RTX 3050

Equipo de Persona 2. Mediciones reales para la evaluacion E3-09. **Solo datos propios medidos**; ninguna cifra se copia de fuentes externas.

- Integracion principal: [benchmarks/README.md](../README.md)
- Datos crudos E3-09: `benchmarks/resultados/intel-i5-12500h-rtx-3050/e3-09/<modelo>/` (`salidas.jsonl` y `reporte.json`)

## Hardware

| Componente | Especificacion |
|---|---|
| CPU | 12th Gen Intel Core i5-12500H, 12 nucleos / 16 hilos |
| RAM | 16 GB, 15.6 GB utilizables |
| GPU | NVIDIA GeForce RTX 3050 Laptop, 4 GB VRAM, driver 610.74 (no se usa: `num_gpu = 0`) |
| SO | Windows 11 Home Single Language, build 26200 |
| Runtime | Ollama 0.40.16 |

Portatil de uso personal con aplicaciones abiertas durante la medicion. Las corridas de E3-09 fuerzan CPU con `num_gpu = 0` y registran la VRAM pico con `nvidia-smi` para confirmar que el modelo no la usa.

## Metodologia E3-09

Script: [`docs/especificaciones/evaluar-fidelidad.py`](../../docs/especificaciones/evaluar-fidelidad.py) contra la API local de Ollama.

- Entrada: los 28 perfiles del split de evaluacion de E3-06 (`sha256(id) % 5 == 0`), con el mismo par system/user del entrenamiento de E3-08.
- Salida: `num_predict = 1200`, `temperature = 0.2`, `seed = 42`, una corrida por perfil tras una carga de calentamiento que no se mide.
- RAM: pico RSS de los procesos de Ollama con el muestreador de [`benchmark.py`](../benchmark.py) cada 0.2 s.
- Fidelidad: 4 dimensiones (exactitud numerica, coherencia del cruce, estructura, guardrails) y promedio global frente a la meta de 85 %.
